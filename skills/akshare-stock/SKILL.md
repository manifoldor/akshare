# AKShare A 股行情查询技能指南

本技能指导 Grokbot 如何利用 AKShare 提供的金融数据接口查询 A 股（沪市、深市、北交所）股票价格、盘口、历史走势及大盘行情。

---

## 1. 触发场景

当用户提出以下需求时，触发并使用本技能：
* **实时股价查询**：“贵州茅台现在多少钱？”、“查一下 000001 的实时股价”、“宁德时代今天涨了还是跌了？”
* **买卖盘口查询**：“查看比亚迪的五档买卖盘口”、“查看 600519 的买一卖一挂单量”
* **历史 K 线/走势查询**：“看下宁德时代最近一个月的走势”、“调取贵州茅台今年以来的日K线”
* **日内分时查询**：“今天平安银行的盘中分时走势如何？”
* **大盘指数查询**：“今天大盘怎么样？”、“上证指数是多少点？”、“创业板指涨跌幅”
* **股票代码检索**：“隆基绿能的股票代码是什么？”、“帮我搜索带有'芯片'的股票”
* **个股基础信息**：“查一下中芯国际的总市值、市盈率和所属行业”

## 2. A 股市场核心规则与展示规范

### 2.1 颜色与涨跌指示（中国 A 股惯例）
在展示 A 股行情时，**必须严格遵循中国内地股市惯例**（与欧美股市相反）：
* 🔴 **红色（加号 `+`）**：代表**上涨**。
* 🟢 **绿色（减号 `-`）**：代表**下跌**。
* ⚪ **灰色/白色（`0.00%`）**：代表**平盘**。

### 2.2 交易时间（北京时间 CST，周一至周五，法定节假日休市）
* 早盘集合竞价：09:15 - 09:25
* 连续竞价早盘：09:30 - 11:30
* 连续竞价午盘：13:00 - 15:00
* 盘后定价交易：15:05 - 15:30（部分科创板/创业板股票）
* **非交易时间提醒**：若用户在闭市时间查询实时行情，返回的通常为最近一个交易日的收盘价或盘后最终快照，应在回复中注明。

### 2.3 涨跌幅限制
* 主板（沪深）：常规股票 ±10%，ST/`*`ST 股票 ±5%
* 创业板（300xxx）/ 科创板（688xxx）：±20%（新股上市前5个交易日不设涨跌幅）
* 北交所（8xxxxx / 4xxxxx / 9xxxxx）：±30%

## 3. 可用工具（MCP Tools）与调用决策

| 工具名称 | 功能描述 | 核心入参 | 适用场景 |
| :--- | :--- | :--- | :--- |
| `get_stock_quote` | 获取个股最新实时行情与五档盘口 | `symbol`: 6位股票代码 | 查询最新价、涨跌幅、五档挂单、成交量/额 |
| `get_stock_history` | 获取个股历史 K 线数据 | `symbol`, `period`('daily'/'weekly'/'monthly'), `start_date`, `end_date`, `adjust`('qfq'/'hfq'/'') | 回测、趋势分析、历史高低点 |
| `get_stock_intraday` | 获取个股日内分时成交数据 | `symbol`: 6位股票代码 | 盘中走势、日内分时波动 |
| `get_index_quote` | 获取大盘及重要指数行情 | `symbol`: 指数代码（默认 `000001` 上证指数） | 上证指数、深证成指、创业板指、科创50 |
| `search_stock` | 根据名称或拼音关键词模糊搜索股票 | `keyword`: 股票名称或拼音缩写 | 用户只提供公司简称或模糊名称时 |
| `get_stock_info` | 查询个股详细公司与估值资料 | `symbol`: 6位股票代码 | 总市值、流通市值、PE(TTM)、PB、所属行业等 |

---

## 4. 标准执行流程

1. **识别标的**：
   * 若用户提供了标准 6 位股票代码（如 `600519`），直接调用相应工具。
   * 若用户仅提供了股票名称（如“五粮液”），若内置映射已知则直接转为代码（如 `000858`），若不确定则先调用 `search_stock` 进行检索。
2. **选择工具**：
   * 最新价格/盘口 -> `get_stock_quote`
   * 走势/涨幅/K线 -> `get_stock_history`
   * 宏观/大盘 -> `get_index_quote`
3. **格式化输出**：
   * 将数据以结构清晰的 Markdown 表格与要点卡片呈现。
   * 标注数据更新时间及关键指标单位（成交量：手/万手；成交额：亿元）。
